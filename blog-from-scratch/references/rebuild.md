# 重建:设计台阶与造直觉

## 台阶设计

从**读者已有的世界**出发,到**作者的啊哈时刻**结束。倒着设计:先确定终点,再问"要让读者在这里点头,他必须先理解什么",依次往前推,直到推到常识为止。这条链就是台阶。

每个台阶遵循同一个小节奏:

1. **承接缺口**:上一步留下了什么没解决的?(读者应当带着这个问题进来)
2. **先失败**:用最朴素的办法试一下,让它出问题——最好真的在小例子上演示。
3. **新东西**:引入一个概念/改动,只一个。
4. **小例子过一遍**:小到能手算的数字或场景,逐步展开,不跳步。
5. **留下缺口**:这个办法还差什么,引到下一台阶。

不是每个台阶都要五步齐全;但"先失败"和"小例子"最不要省。

## 造直觉的手法

按需选用,不要全用:

- **缩小规模**:把问题缩到 3 个元素、2 个数字,直觉才看得见。
- **换一个熟悉的场景**:类比要明说"哪里像、哪里不像",否则类比会带来错误直觉。
- **极端情况**:把参数推到 0 或无穷,看结论是否仍合理。
- **反事实**:去掉某个部分会怎样?这个部分到底在干什么。
- **前后对比表**:同一个输入,天真做法 vs 作者做法,并排。
- **量一量**:能测的就测,用真实数字替代形容词。

## 心智模型的检验标准

候选模型必须同时满足:

1. **一句话说得清**(不超过两行,不依赖本文上下文)。
2. **能预测**:遇到新情形,用它能推出该怎么做/会发生什么。
3. **能迁移**:能举出本文之外的至少一个场景。
4. **有边界**:知道它在什么情况下不适用。

只满足前一条的是口号,不要收。

## 检验题

文末给 3–5 道题,考的是理解而非记忆:

- 一道**复述**:不看原文,解释核心论证。
- 一道**预测**:给一个新情形,问会怎样。
- 一道**迁移**:这个思路还能用在哪?
- 可选一道**反例**:什么时候它不成立?

每题附简短参考思路(折叠或放在题后),方便读者自查。
