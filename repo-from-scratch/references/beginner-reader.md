# 读者画像与前置阶梯

## 读者画像

- **会**:基础 Python —— 变量、函数、循环、if、dict/list、字符串、用 uv/pip 装包、跑脚本看输出。
- **不会(也不要求预习)**:PyTorch 与任何 ML/领域框架;线性代数(矩阵、点积、转置);概率(分布、期望、采样、softmax)。
- 判断标准:写每一节时,把每个新概念都当作读者**第一次见到**——先定义再用。

## 前置阶梯盘点(写作前必做,流程见 `repo-dissection.md` 阶段 4)

1. 把全书将用到的所有前置概念列出来(遍历每个阶梯、每个公式符号、每次库调用):
   | 去向 | 条件 | 做法 |
   |---|---|---|
   | 该章正文/旁枝 | 只被一章使用 | 仍是先定义后用,讲完为止 |
   | 附录 B | 稍复杂、读不读都不影响主线、自成一体 | 见 `appendix-policy.md` |
   | 附录 A + 术语表 | 被 ≥2 章使用 | 附录 A 开一节(可运行、≤15 行块、预测练习)+ 术语表一条 |
   | 第 1 章 | 全书脚手架(梯级、对账、诚实边界的读法) | 第 1 章讲透,后文只回指 |
2. 附录 A 每节要能被独立运行;变量名统一加 `a_` 前缀,避免污染各章共享的命名空间。
3. 门禁:从第 2 章起,读者遇到的每个术语要么已定义,要么列在当章"本章新术语"框;`lint_chapter.py` 会在同目录存在 `glossary.md` 时自动核对(术语在被正文使用前必须先列出)。

## 附录 A 默认目录(模板在 `templates/appendix-basics.md`,按仓库裁剪)

Python 数值/ML 类仓库的默认阶梯:A.1 张量与形状 → A.2 索引/reshape/transpose/expand → A.3 矩阵乘法 `@` → A.4 softmax(手算再代码)→ A.5 `nn.Module` 与 `nn.Linear` → A.6 autograd:梯度与 `backward` → A.7 交叉熵与 logits → A.8 随机种子与可复现。
非 ML 仓库时把 A.3–A.7 换成该领域的最小基础(例如校验和/正则/HTTP 报文),但保留"手算 → 代码 → 预测练习"的讲法。

## 术语表条目格式(模板在 `templates/glossary.md`)

| 术语 | 定义 | 先在哪章完整讲 |
|---|---|---|
| `对账` | 与原实现/同一输入对比输出 | ch01 |

- `术语` 用反引号(英文名在前)或中文名,一个词;**定义**一句话,直觉在前、公式在后;`先在哪章完整讲` 填章号或"附录 A"。
- 每章的"本章新术语"框 = 该章新增条目的清单;完稿后和本表对齐。
