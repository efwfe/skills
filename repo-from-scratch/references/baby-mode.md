# baby 模式:内核不适合完整重建时(适配度 C 档)

抽核心思想做一个小型实现,**以心智模型为主要交付物**。

## 主交付物:心智模型卡

每个组件一张,模板 `templates/mental-model-card.md`,五件:

- 要解决的问题;
- 一句话核心思想;
- 一张图;
- 3–5 条不变量(写成 `assert`);
- 放大到真实规模会变什么。

卡里的一句话核心思想与五个心智模型(`voice.md` §二)中的哪一个相对应,写明。

## baby 实现

- 几百行以内;3–6 个梯级,每级只加一个概念;每级有真实运行的输出和 `assert`。
- 仍守全书默认做法:代码块 ≤15 行、先失败要真的运行、输出由脚本写入、固定随机种子、图注单写、"我们"统一、无元文字、诚实边界集中放置。
- baby 模式不因为小而放松默认做法,只换对账方式与必备小节(见下)。

## 对照表

每章一张三列表:baby 保留了 / 砍掉了 / 真实仓库对应哪里(写 `path:line`)。

## "预言机"的含义(本模式专用)

不再是"输出与原仓库一致",而是二选一或都做:

- (a) 不变量断言:每个梯级的性质写成 `assert`;
- (b) 能做的地方,在小输入上与原仓库对比行为(不要求逐字相同);不能做的,写进"诚实边界"框。

## 每章必有:"与真实实现的差距"小节

说明砍掉了什么、为什么砍,防止读者把 baby 的做法当成真实仓库的做法。缺这一节,`lint_chapter.py --mode baby` 判违规。

## 书的结构

1. 先讲心智模型:全书一张总图 + 每个组件一张卡;
2. 再按梯级搭 baby;
3. 最后一章"从 baby 到真实仓库":带读者读真实代码,给出阅读路线(`path:line`)。

## 诚实边界

每章框内明说一句话:**这是复刻思想,不是复刻实现。**
