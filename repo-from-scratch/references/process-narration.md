# 流程怎么讲:顺序、注解、逐步追踪

凡是讲一个**有先后顺序的过程**(一次前向计算、一个算法、一条数据流),都按本文件讲。读者看不见的东西越多——token、隐状态(潜层)、算法的中间量、梯度、缓存——越要细:让他在每一步都知道"现在到哪了、手里拿着什么、下一步拿它做什么"。

以下是默认做法;读者靠更少的标注就能跟上时,可以精简,但抽象对象不要省。

## 一、先给全貌,再逐步

1. 一句话总流程:"输入是 X,经过这几步,得到 Y。"
2. 一份编号清单(①→⑥),每步一行:**做什么 → 输入 → 输出(类型或 shape)**。读者只看这份清单就能复述流程。
3. 之后每一步展开,展开时标题或开头带同一个编号。

## 二、编号贯穿四处

同一个编号,在**正文、代码注释、图、输出**里指同一件事:

| 位置 | 写法 |
|---|---|
| 正文 | "① 切分:……""② 查表:……" |
| 代码 | `# ① 切分`、`# ② 查表`,一步一行注释,与正文编号一致 |
| 图 | 箭头旁标 ①②③;分支用 ②a / ②b,循环标"重复 N 次" |
| 输出 | 打印时带编号:`print("② ids:", ids)`,读者能把输出对回步骤 |

## 三、每一步讲四件事

1. **做什么**:一个动词开头的短句。
2. **输入是什么**:名字、类型、shape,最好附真实的前几个值。
3. **输出是什么**:同上。
4. **为什么要这一步**:一句话,说明没有它会缺什么(能接上"先失败"就更好)。

## 四、逐步追踪表

选**一个最小的具体例子**,从头走到尾,每步一行,值取自真实运行:

| 步 | 做什么 | 此时的值 | shape |
|---|---|---|---|
| ① 切分 | 字符串 → token | `{真实的切分结果}` | 长度 {n} |
| ② 查表 | token → id | `{真实的 ids}` | ({n},) |
| ③ 嵌入 | id → 向量 | `{前几个数}…` | ({n}, {d}) |

追踪表放在逐步讲解**之后**做总结,或放在**之前**做预告,二选一,不要两处都放。表里的数字一律来自运行输出。

## 五、抽象对象:越抽象越要细

**token**
- 先打印字符串、切分结果、id、再翻回字符串,让读者看见每一层。
- 说清"token 不等于词":拿一个会被切开的词作例子,打印真实切分。
- 说清谁产生它(分词器)、谁读它(嵌入层)、它的取值范围。

**隐状态 / 潜层(hidden state、latent)**
- 先说它**是什么**:一个长度为 d 的向量(或一个 shape 的张量);再说它**在哪一步产生、谁会读它**。
- 打印它的 shape 和前几个数,让它从"一个概念"变成"手里的东西"。
- 不只说"它表示语义"。给一个可感的对比:两个相近输入的隐状态距离,与两个无关输入的距离,打印出来。
- 每经过一层,写出 shape 的变化与"这一层往里加了什么"。

**算法(迭代、搜索、采样、优化)**
- 先写**编号的伪代码**,再让每一行对应一段代码。
- 在一个小例子上**逐轮追踪**:展示第 1 轮、第 2 轮和最后一轮的状态,中间省略要说明省略了几轮。
- 循环的"不变量"和"终止条件"各用一句话点明。

## 六、并行、分支、循环怎么标

- 并行:②a、②b,在汇合处写"②a 与 ②b 的结果合并为 ③"。
- 分支:写明条件,"若 X 则走 ③a,否则走 ③b"。
- 循环:写"重复 N 次",并给出一轮内部的子步骤编号(③.1、③.2)。

## 七、对照

> 说明式:前向传播首先对输入进行嵌入,然后经过若干层变换得到输出表示。
>
> 追踪式:一次前向有四步。① 切分:`"我爱你"` 变成 3 个 token。② 查表:每个 token 换成一个整数 id,得到 `{真实 ids}`。③ 嵌入:每个 id 换成长度 {d} 的向量,shape 从 ({n},) 变成 ({n}, {d})。④ 过一层:shape 不变,但每个位置的向量里混入了别的位置的信息。下面逐步运行,每一步打印它的结果。(花括号处在书里一律填运行得到的真实值。)

## 八、自检

1. 只看编号清单,能不能复述整个流程?
2. 每个编号,在正文、代码注释、图、输出四处是否对得上?
3. 读者没见过的对象(token、隐状态、中间量),是否至少被打印出一次真实的值?
4. 每一步是否说了"为什么要这一步"?
